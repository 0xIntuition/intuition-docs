The Intuition testnet uses **tTRUST** for gas and native call value. Select chain ID `13579` and copy the public receiving address you want to fund. [Testnet network settings](/docs/reference/networks)

Open the [Intuition testnet hub](https://testnet.hub.intuition.systems/) and follow its current faucet instructions. Use the amount and eligibility requirements shown there.

After a transfer is confirmed, look up the receiving address in the [testnet explorer](https://testnet.explorer.intuition.systems). If you see a zero balance, check the network and receiving address against the faucet request. Mainnet TRUST balances are tracked separately.
