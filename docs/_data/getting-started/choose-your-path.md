Choose a starting point based on the result you want. If you are new to Intuition, [Build with Intuition](../build/overview.md) takes you from the data model to a runnable local graph.

| I want to…                                 | Start here                                                                                                         |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| Learn atoms, triples, and signals          | [Building blocks](../build/concepts.md)                                                                            |
| Run my first example                       | [Create your first atom](../build/guides/first-atom.md)                                                            |
| Combine entities and relationships         | [Build a music catalog](../build/guides/music-catalog.md)                                                          |
| Query existing graph data                  | [Query the graph](../build/guides/sdk-reads.md) or [GraphQL setup](../graphql-api/getting-started/client-setup.md) |
| Add provider metadata                      | [Process and enrich atoms](../build/guides/processing.md)                                                          |
| Connect a wallet and prepare a transaction | [On-chain actions](../build/guides/onchain.md)                                                                     |
| Add protocol hooks to React                | [React package](../build/packages/react.md)                                                                        |
| Find a library or function                 | [Packages](../build/packages/index.md) or [API reference](../build/sdk-reference/index.md)                         |
| Update an existing integration             | [Upgrade guide](../build/migration.md)                                                                             |

## Learn with a course, starter, or agent

[Learn Intuition](./learn-intuition.md) offers a guided course through protocol concepts and application development. [Templates](./templates.md) provide working applications to explore and extend. Check each template's dependencies before copying code into a project using a different package version.

For coding agents, start with [Build with AI agents](../build/agents.md) and the [AI skills](./ai-skills.md). For an AI application that needs graph tools, see the [MCP server](../experimental-applications/mcp-server.md).

## Understand the infrastructure

Read [application architecture](../build/architecture.md) to choose between local modeling, hosted queries, your own graph backend, and contract interactions. Use [network details](../quick-start/network-details.md) and [deployments](../quick-start/deployments.md) when your application is ready to connect to a chain.
